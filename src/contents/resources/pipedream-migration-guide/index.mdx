faq:
  - question: "Is Pipedream shutting down?"
    answer: 'Pipedream Workflows and String are. Pipedream''s own documentation states both shut down on March 31, 2027, that Workflows is in maintenance mode with no new signups, and that all Workflows data, including credentials and OAuth tokens, is deleted by April 30, 2027. Pipedream Connect, the integration layer for AI agents, continues. See <a href="#pd-dates-title">the shutdown dates</a>.'
  - question: "Can I import the Pipedream JSON export directly into Kestra?"
    answer: 'No. The export is the specification you convert from. A coding agent with the Kestra agent skills, or the AI Copilot in Kestra Cloud, turns each workflow file into a draft flow that you review. See <a href="#pd-steps-title">the migration steps</a>.'
  - question: "Do my code steps need rewriting?"
    answer: 'The logic copies into a Script task in the same language. Two lines change: the step reads its input from <code>{{ trigger.body }}</code> or an earlier task''s outputs instead of <code>pd.steps</code>, and it exports its result with <code>Kestra.outputs()</code> instead of <code>return</code> (an <code>::{"outputs":…}::</code> line in Bash).'
  - question: "What happens to my connected accounts?"
    answer: 'They do not migrate. The export keeps only an internal <code>authProvisionId</code>. Register your own OAuth client or API token for each app and store it in Kestra''s secret manager, scoped to a namespace. Set <code>allowedNamespaces</code> on a namespace such as <code>finance</code> so flows elsewhere can''t read its secrets.'
  - question: "How do I handle NetSuite tokens?"
    answer: 'Don''t store the access token: NetSuite OAuth 2.0 tokens last 60 minutes. The client-credentials flow signs a JWT with a certificate, using PS256 or ES256 (NetSuite rejects RS256). Store the client ID, certificate ID and private key as secrets, request the token in a script task and make the call from the same script. Task outputs are stored in clear text, so return a token only as an encrypted output (<code>::{"encryptedOutputs":{"token":"..."}}::</code>).'
  - question: "How do I move Data Stores?"
    answer: 'Export each store with Pipedream''s chunked-export action, with <code>shouldDeleteKeys</code> set to <code>false</code> so live workflows keep their data. Load it into the KV Store with a one-off flow, then replace <code>this.&lt;store&gt;.get()</code> and <code>.set()</code> (Node.js) or <code>pd.inputs["data_store"]</code> (Python) with <code>{{ kv(''key'') }}</code> and the <code>io.kestra.plugin.core.kv.Set</code> task.'
  - question: "How do I size the migration?"
    answer: 'Retire workflows marked <code>skipped_never_deployed</code> or not run in 90 days, and merge copies per environment into one flow with inputs. Before Pipedream''s history goes, note executions per month, steps per execution and the concurrency setting of each busy workflow. Executions times steps is your monthly step count. A 60-workflow estate fits in about three months, including one month-end close.'
  - question: "What about API calls that take minutes?"
    answer: 'Set <code>timeout</code> on the task to the value the call needs. For an HTTP call, also raise <code>options.timeout.readIdleTimeout</code>, as the <a href="#pd-compare-title">worked conversion</a> does.'
  - question: "How does concurrency work?"
    answer: 'A trigger starts one execution at a time unless you set <code>allowConcurrent: true</code>, which webhook-driven flows usually need. You can also cap executions per flow, namespace or tenant; executions above the cap queue by default, or fail or cancel.'
  - question: "How is Kestra Cloud priced compared to credits?"
    answer: 'By task runs, plus compute time for scripts that run on the Kestra Cloud task runner. A task run is one run of one task; loops, conditions and triggers are not counted. Scripts sent to your own AWS, GCP or Azure runners still count as task runs, but your cloud provider bills their compute. <a href="/demo">Send us your monthly step count</a> and we size the plan.'
  - question: "How does Kestra compare with other Pipedream alternatives?"
    answer: 'If you are still choosing where to move, <a href="/resources/infrastructure/pipedream-alternatives">Pipedream Workflows alternatives</a> gives four tests to run on any replacement before the shutdown, and <a href="/vs/pipedream">Kestra vs. Pipedream</a> compares the two side by side.'
  - question: "Is Pipedream Connect affected?"
    answer: 'No. Only Workflows and String shut down. If you only use Pipedream Connect, its API, MCP servers or API proxy, nothing changes. Source: <a href="https://pipedream.com/docs/workflows" target="_blank" rel="noopener">Pipedream''s notice</a>.'
