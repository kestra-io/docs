Kestra supports three paths for moving flows between environments: Git-based sync (GitOps, Git as source of truth), CI/CD pipelines (GitHub Actions, Terraform, etc.), and [Promote](./06.promote/index.md) (EE — UI-first, no Git required). Choose based on whether your team is Git-native, pipeline-driven, or UI-first.
