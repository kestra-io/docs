Write flows in the editor you already use. The Kestra extensions for VS Code and JetBrains IDEs connect to your Kestra instance, so completion and validation match the plugins installed there. You can preview a flow's topology and run it without leaving the editor.

| Extension | Editors | Install from |
| --- | --- | --- |
| [VS Code extension](./01.vscode/index.md) | VS Code and editors based on it, such as VSCodium and Cursor | VS Code Marketplace or Open VSX |
| [JetBrains plugin](./02.jetbrains/index.md) | IntelliJ IDEA, PyCharm, WebStorm, GoLand, and other IntelliJ Platform IDEs | JetBrains Marketplace |

To sync flows with a Git repository or deploy them from a pipeline, see [Version Control & CI/CD](../version-control-cicd/index.mdx).
