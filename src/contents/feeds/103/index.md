What's in it:

- ⚙️ A new decoupled engine lets you run a queue on the backend of your choice (Redis, AMQP, Kafka, JDBC)
- 🌍 Workers and Schedulers can be run and scaled independently, anywhere you have outbound network access
- 🚦 Worker queues can route tasks by priority and available capacity
- 🤖 Flows can now be called as tools by any AI agents via the built-in MCP Server(s)
- 🧠 An AI Copilot is now reachable from a chat panel with memory
- 🤹 Agent Skills let you write (or migrate from 1.3!) flows from Claude Code, Cursor, or any other coding agent
- 🛡️ Quotas and Policies provide governance rules enforced when a flow is saved or executed
- 🚨 Cases can track executions as incidents and alert you about them via in-app Notifications
- 🔁 Drafts and Promote help build flows iteratively, test in dev, then move to prod, all natively from the UI or API
- 🧩 Plugin artifacts allow plugins to adjust topology nodes or any other UI components
- ✨ A redesigned UI with 1 light and 2 dark modes! (LPT: you can toggle between them via Control + Shift + L)

And we are excited to announce that 2.0 is an LTS release, which means we're committed to a year of backporting fixes to it.

Thank you to the engineers who built this, for the care that went into every part of it. And we want to thank all users and customers: much of the list above was first raised in a GitHub issue, a support ticket, or a Slack conversation with someone running Kestra in production, and this will continue to be the fastest way to influence what we build next. Keep it coming 💙
